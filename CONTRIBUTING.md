# Contributing

This is a personal research-learning project, but thoughtful feedback is welcome.

## Principles

- Prioritize biological correctness over clever code.
- Explain assumptions, not just outputs.
- Use original examples, simulations, or openly licensed data.
- Cite methods, software, and datasets.
- Do not submit or request direct Rosalind solutions, challenge datasets, or challenge-answer code in this public repository.
- Keep documentation concise, beginner-friendly, and technically precise.

## Proposing an improvement

Open an issue describing the biological question, the proposed computational change, validation approach, and any relevant references. For public materials, prefer general concepts and independently designed examples over exercise-specific answers.
