# Applied capstones

The capstones are where algorithmic mastery becomes research practice. Each project will use original simulations or openly licensed data, document assumptions, and include reproducible outputs.

## Planned projects

### 1. Sequence quality and composition

Build transparent sequence summaries from FASTA/FASTQ inputs, including GC distribution, ambiguous-base content, length distribution, and quality-aware filtering logic.

### 2. Assembly concepts in a controlled dataset

Construct and inspect a small de Bruijn graph from simulated reads. Compare graph topology, contiguity, and repeat behaviour under changing k-mer sizes.

### 3. Alignment decision laboratory

Demonstrate how global, local, overlap, and affine-gap alignment answer different biological questions. Include controlled examples and comparisons with established software.

### 4. Phylogeny with interpretation safeguards

Construct a small tree from a curated alignment and report model assumptions, uncertainty limits, rooting decisions, and sensitivity checks.

### 5. Microbial pangenome bridge

Use a small, openly accessible microbial genome collection to show how sequence similarity, gene presence–absence, phylogenetic context, and graph-like variation complement one another. This is the project that connects the atlas to Muhammad Bilal’s research in microbial evolutionary genomics.

## Capstone standard

Each capstone must answer a biological question, make the computational choices visible, and show what would change the interpretation. Attractive figures are not enough; every output needs a traceable path back to data and methods.
