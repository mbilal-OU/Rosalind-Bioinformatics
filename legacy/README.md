# Legacy materials

This repository began as a small set of exploratory notebooks covering introductory sequence exercises, GC content, recurrence relations, complements, transcription, and point mutations.

They are preserved in the repository history as the starting point of the learning journey. The project is now being reorganized around a public concept-and-capstone atlas and a separate private workspace for challenge implementations, in line with Rosalind’s publication guidance.

No legacy material should be interpreted as evidence of full curriculum coverage or current code-quality standards.
